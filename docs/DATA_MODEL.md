# Rebuild Data Model

This is the proposed rebuild schema. PostgreSQL types are shown in SQL-like terms. All timestamps are timestamptz stored in UTC and generated by the database unless a trusted signing service's timestamp is separately recorded.

## Entities

### User

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| email | citext | Required; unique |
| display_name | text | Required |
| created_at | timestamptz | Required; default database current timestamp |

### Document

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| owner_user_id | uuid | Required FK to User(id); index |
| letter_type | enum(OD, PERMISSION) | Required |
| title | text | Required |
| status | enum(DRAFT, PENDING, PROCESSING, COMPLETED, CANCELLED, INTEGRITY_FAILED) | Required |
| current_version_id | uuid | Nullable until upload; composite FK (id, current_version_id) to DocumentVersion(document_id, id) |
| audit_next_sequence | bigint | Required; default 1 |
| audit_head_hash | bytea | Required; genesis hash on creation |
| created_at | timestamptz | Required; database current timestamp |
| sent_at | timestamptz | Nullable |
| completed_at | timestamptz | Nullable |

Indexes: (owner_user_id, created_at DESC), (status, created_at).

### Signer

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| document_id | uuid | Required FK to Document(id) ON DELETE CASCADE |
| sequence | smallint | Required; CHECK 1 through 3 |
| role | enum(STUDENT, FACULTY_ADVISOR, HOD) | Required |
| full_name | text | Required |
| email | citext | Required |
| identity_subject | text | Nullable external verified identity |
| token_digest | bytea | Required; unique; store digest, never bearer token |
| status | enum(PENDING, ACTIVE, SIGNED, REVOKED) | Required |
| invited_at | timestamptz | Nullable |
| activated_at | timestamptz | Nullable |
| signed_at | timestamptz | Nullable |

Constraints: UNIQUE(document_id, sequence); UNIQUE(document_id, role); UNIQUE(token_digest); UNIQUE(id, document_id) for same-document composite references. Enforce exact pairs (1, STUDENT), (2, FACULTY_ADVISOR), (3, HOD) in a server transaction and, if available, a deferred database constraint trigger. Index (document_id, status, sequence).

### DocumentVersion

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| document_id | uuid | Required FK to Document(id) ON DELETE CASCADE |
| version_number | integer | Required; CHECK > 0 |
| object_key | text | Required; unique immutable storage key |
| sha256 | bytea | Required; exactly 32 bytes |
| byte_length | bigint | Required; CHECK > 0 |
| media_type | text | Required; must be application/pdf |
| state | enum(SOURCE, SEALED, SUPERSEDED) | Required |
| created_at | timestamptz | Required; database current timestamp |
| sealed_at | timestamptz | Nullable |
| pdf_signature_metadata | jsonb | Nullable; certificate/algorithm/signature validation details |
| integrity_manifest | jsonb | Nullable; canonical document/version/digest/signing-time data |
| manifest_signature | bytea | Nullable; KMS signature over canonical manifest |
| kms_key_version | text | Nullable |

Constraints: UNIQUE(document_id, version_number); UNIQUE(object_key); UNIQUE(document_id, id) for composite references. Index (document_id, version_number DESC). Source versions have no manifest signature; sealed versions require digest, sealed_at, manifest, signature, and key version. The Document current-version pointer must reference a version belonging to that same document.

### SignatureField

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| document_id | uuid | Required FK to Document(id) ON DELETE CASCADE |
| source_version_id | uuid | Required; composite FK (document_id, source_version_id) to DocumentVersion(document_id, id) |
| assigned_signer_id | uuid | Required FK to Signer(id) ON DELETE RESTRICT |
| page_number | integer | Required; CHECK > 0 |
| x_norm | numeric(8,7) | Required; CHECK 0 <= value <= 1 |
| y_norm | numeric(8,7) | Required; CHECK 0 <= value <= 1 |
| width_norm | numeric(8,7) | Required; CHECK 0 < value <= 1 |
| height_norm | numeric(8,7) | Required; CHECK 0 < value <= 1 |
| field_type | enum(SIGNATURE, INITIALS, DATE, TEXT) | Required |
| required | boolean | Required; default true |
| created_at | timestamptz | Required; database current timestamp |

Constraints: UNIQUE(id, assigned_signer_id); UNIQUE(id, assigned_signer_id, document_id). Composite FK (assigned_signer_id, document_id) to Signer(id, document_id) prevents assigning a field to a signer on another document. Composite FK (document_id, source_version_id) to DocumentVersion(document_id, id). Index (document_id, assigned_signer_id); page geometry is validated against the PDF dimensions before send.

### Signature

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| document_id | uuid | Required; composite FK with field_id to SignatureField |
| field_id | uuid | Required FK to SignatureField |
| signer_id | uuid | Required |
| method | enum(DRAWN, TYPED, UPLOADED, CERTIFICATE) | Required |
| value | text | Nullable; non-image typed value only |
| image_object_key | text | Nullable; private object key for image data |
| signed_at | timestamptz | Required; database current timestamp |
| request_id | uuid | Required idempotency key |
| client_metadata | jsonb | Optional non-authoritative device details |

Constraints: UNIQUE(field_id) ensures at most one current signature per field. UNIQUE(signer_id, request_id) supports idempotent submission. Composite FK (field_id, signer_id, document_id) references SignatureField(id, assigned_signer_id, document_id) so only the assigned signer may sign their field on the same document. UNIQUE(id, document_id) supports audit references. Index (signer_id, signed_at DESC).

### DocumentView

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| document_id | uuid | Required FK to Document(id) ON DELETE CASCADE |
| version_id | uuid | Required; composite FK (document_id, version_id) to DocumentVersion(document_id, id) |
| signer_id | uuid | Nullable; composite FK (document_id, signer_id) to Signer(document_id, id) |
| user_id | uuid | Nullable FK to User(id) |
| viewed_at | timestamptz | Required; database current timestamp |
| request_id | uuid | Required unique idempotency/request identifier |
| ip_address | inet | Optional, subject to retention policy |
| user_agent | text | Optional |

Constraints: UNIQUE(request_id). Do not unique by signer/document: repeated valid views are separate records. UNIQUE(id, document_id) supports same-document audit references. Index (document_id, viewed_at DESC), (signer_id, viewed_at DESC).

### AuditEvent

| Field | Type | Constraints |
|---|---|---|
| id | uuid | Primary key |
| document_id | uuid | Required FK to Document(id) ON DELETE RESTRICT |
| sequence | bigint | Required |
| event_type | enum(DOCUMENT_CREATED, DOCUMENT_SENT, DOCUMENT_VIEWED, FIELD_SIGNED, SIGNER_COMPLETED, DOCUMENT_SEALED, INTEGRITY_FAILED, DOCUMENT_CANCELLED) | Required |
| actor_type | enum(REQUESTER, SIGNER, SYSTEM) | Required |
| actor_user_id | uuid | Nullable FK to User(id) |
| actor_signer_id | uuid | Nullable FK to Signer(id) |
| view_id | uuid | Nullable FK to DocumentView(id) |
| signature_id | uuid | Nullable FK to Signature(id) |
| occurred_at | timestamptz | Required; database current timestamp |
| details | jsonb | Required; validated event-specific metadata |
| previous_hash | bytea | Required |
| event_hash | bytea | Required; SHA-256 over canonical event plus previous hash |
| event_signature | bytea | Required; KMS signature over event_hash |
| kms_key_version | text | Required |

Constraints: UNIQUE(document_id, sequence); UNIQUE(view_id) when not null; UNIQUE(signature_id) when not null; CHECK actor_user_id is set only for REQUESTER, actor_signer_id only for SIGNER, and neither is set for SYSTEM. Composite FKs (view_id, document_id) to DocumentView(id, document_id) and (signature_id, document_id) to Signature(id, document_id) prevent cross-document event links. Append-only database permissions; no UPDATE/DELETE API. Index (document_id, sequence), (document_id, occurred_at), (event_type, occurred_at).

## Relationships

~~~mermaid
erDiagram
  USER ||--o{ DOCUMENT : owns
  DOCUMENT ||--o{ SIGNER : has
  DOCUMENT ||--o{ DOCUMENT_VERSION : versions
  DOCUMENT o|--o| DOCUMENT_VERSION : current_version
  DOCUMENT ||--o{ SIGNATURE_FIELD : defines
  SIGNER ||--o{ SIGNATURE_FIELD : assigned
  SIGNATURE_FIELD ||--o| SIGNATURE : receives
  SIGNER ||--o{ SIGNATURE : creates
  DOCUMENT ||--o{ DOCUMENT_VIEW : viewed
  USER o|--o{ DOCUMENT_VIEW : views
  SIGNER o|--o{ DOCUMENT_VIEW : views
  DOCUMENT_VERSION ||--o{ DOCUMENT_VIEW : viewed_version
  DOCUMENT ||--o{ AUDIT_EVENT : records
  SIGNER o|--o{ AUDIT_EVENT : actor
  USER o|--o{ AUDIT_EVENT : actor
  DOCUMENT_VIEW o|--o| AUDIT_EVENT : produces_view_event
  SIGNATURE o|--o| AUDIT_EVENT : produces_signature_event
~~~

The signed field relationship is constrained by the composite foreign key: Signature(field_id, signer_id, document_id) must reference SignatureField(id, assigned_signer_id, document_id). Every successful view creates one DocumentView and one linked DOCUMENT_VIEWED AuditEvent in the same transaction. Every signature creates a Signature and linked FIELD_SIGNED AuditEvent in the transaction that validates and advances signer state. A draft may initially have no signers; the send transaction requires the complete three-signer set.

## Killer Test support

- **KT1:** Signer.sequence and role encode the required order; status encodes PENDING/ACTIVE/SIGNED. Unique constraints prohibit duplicate role/sequence per document. The API must lock the document and independently derive the ACTIVE signer before any Signature write. Schema state alone is not the order-enforcement mechanism.
- **KT2:** DocumentVersion stores immutable object key, SHA-256 digest, and KMS-signed manifest for the exact sealed bytes. Retrieval recomputes bytes' digest and verifies the manifest signature. A mismatch is recorded and rejected.
- **KT3:** Each fetch creates a distinct DocumentView with database timestamp and linked AuditEvent; each Signature and linked event have database timestamps. Per-document sequence plus previous/event hashes and KMS signatures make audit edits detectable.

Cross-row invariant note: ordinary SQL CHECK constraints cannot require exactly one row of each role across a document's signer set. Enforce the three-role set in the same server transaction that sends a draft, with a deferred constraint trigger if operationally supported.
